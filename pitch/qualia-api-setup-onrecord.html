Setup Overview

To integrate TitleSuperTools with your Qualia account, we need API access credentials. This guide walks you through the exact steps to generate your API key and Organization ID.

Minutes Required
Admin
Permission Level
7
Simple Steps

Who Should Complete This:

Qualia admin user (Elena, Spencer, or Christian) with full account permissions.

1
Access Qualia Admin Panel

Direct Link (Recommended)

Go to Qualia API Settings

Navigation Path (if link doesn't work)

  1. 1
    Log into Qualia at https://app.qualia.com
  2. 2
    Click your profile icon (top right corner)
  3. 3
    Select "Settings" from the dropdown
  4. 4
    Click "API & Integrations" in the left sidebar

2
Enable API Access

You should see a page that looks like this:

API Access

☐ Enable API Access

API Key: [Generate New Key]

Organization ID: qual-org-abc123xyz

Actions Required:

  • ✓
    Check the box next to "Enable API Access" (if not already enabled)
  • ✓
    Click the "Generate New Key" button

3
Copy Your API Key

⚠️ CRITICAL WARNING

The API key will only display ONCE. You cannot retrieve it later if you close the window without copying it.

What You'll See:

A modal popup showing:

Your API Key (copy this now):

qual_live_sk_abc123xyz456789...

What to Do:

  1. 1
    Click the copy button or manually select and copy the entire key
  2. 2
    Paste it somewhere secure (password manager, encrypted note, or email to GullStack immediately)
  3. 3
    Verify format: Long alphanumeric string starting with qual_live_sk_

If You Close Without Copying:

You'll need to click "Regenerate Key" and get a new one. The old key becomes invalid. Not a problem, just generates a new key.

4
Copy Your Organization ID

On the same page, you'll see:

Organization ID: qual-org-abc123xyz

What to Do:

  1. 1
    Copy this ID exactly as displayed
  2. 2
    Format verification: Starts with qual-org- followed by random characters
  3. 3
    Example: qual-org-5f8a9b2c1d3e4f

5
Configure API Permissions

Scroll down on the same page to find the API Capabilities section:

API Capabilities

Select which capabilities this API key should have access to:

Enable These Permissions:

Check ALL of the following boxes:

  • ✓
    Orders (Read) — Allows us to pull order data from Qualia
  • ✓
    Orders (Write) — Allows us to auto-populate order fields
  • ✓
    Documents (Read) — Allows us to process uploaded documents
  • ✓
    Documents (Write) — Allows us to attach generated commitments
  • ✓
    Messages (Read) — Allows us to monitor communications
  • ✓
    Messages (Write) — Allows us to send automated emails
  • ✓
    Webhooks (Configure) — Allows real-time event notifications
  • ✓
    Accounting (Read) — Allows closing disclosure balancing

After Selecting:

Click "Save Permissions" button at the bottom of the section.

6
Set Up Webhooks

Still on the API settings page, find the Webhooks section:

Webhooks

Webhook URL: [Enter URL here]

Events to Subscribe:
☐ order.created
☐ order.updated
☐ document.uploaded
☐ status.changed
☐ message.received

Webhook URL

Enter this URL exactly:

https://titlesupertools.railway.app/api/webhooks/qualia

Note: We'll provide the final URL once we deploy the production system

Select These Events:

Check ALL of the following:

  • ✓
    order.created — New order opened
  • ✓
    order.updated — Order details changed
  • ✓
    document.uploaded — New document added to file
  • ✓
    status.changed — Order status updated (e.g., opened → title search → clear to close)
  • ✓
    message.received — New message/email received

Webhook Secret

  • 1
    Qualia will auto-generate a webhook secret
  • 2
    It will look like: whsec_abc123xyz...
  • 3
    Copy this secret and send it to us along with your API credentials

After Configuring:

Click "Save Webhook Settings" button to complete the webhook setup.

7
Test the Connection (Optional but Recommended)

Qualia provides an API Explorer tool to verify your credentials work.

Access the Explorer:

Go to Qualia API Explorer

Run This Test Query:

Copy and paste this into the query box:

query TestConnection { organization { id name createdAt } }

Click "Run Query"

Expected Response:

You should see something like:

{ "data": { "organization": { "id": "qual-org-abc123", "name": "OnRecord Title", "createdAt": "2023-01-15T08:30:00Z" } } }

If It Works:

✅ Your API key is valid and ready to use!

If It Fails:

  • Check that "Enable API Access" is turned on
  • Verify you copied the API key correctly
  • Regenerate the key and try again

Troubleshooting

"I don't see the API & Integrations menu"

Problem:

Your user account doesn't have admin permissions

Solution:

  1. Ask an admin (Spencer or Christian) to check your role
  2. Go to: Settings → Users → [Your Name] → Role
  3. Role must be "Admin" or "Owner" to access API settings

"API key generation failed"

Problem:

Qualia may require 2FA verification

Solution:

  1. Check your email for a verification code from Qualia
  2. Enter the code and try again
  3. If still failing, contact Qualia support

"I closed the modal before copying the API key"

Problem:

You can't retrieve the same key

Solution:

  1. Click "Regenerate Key" button
  2. This creates a new key (old one becomes invalid)
  3. Copy the new key immediately
  4. Not a big deal — just generates a fresh key

"We don't have a sandbox/test account"

Problem:

You only have one production Qualia account

Solution:

  1. We'll use your live account but create test orders
  2. We'll prefix all test orders with "TEST-" so you can identify them
  3. You can delete test orders after we verify everything works
  4. Best Practice: Ask Qualia support for a free sandbox account (usually provided for integrations)
